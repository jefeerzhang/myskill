# 经济管理类文献综述写作框架

本目录为 `econ-literature-review-writer` 的参考材料。该技能由用户指定仓库 `yichaoli921/Economics-Literature-Review-Skills` 审查后改造而来，只保留综述写作、综合分析和 GB/T 7714-2015 引用整理能力。

本技能定位为通用写作技能，不绑定任何学校、机构或期刊库标准。它只处理用户已经给出的文献材料，不改变用户指定的文献集合。

## 适合场景

- 根据用户手动提供的一篇文献做精读分析；`r`n- 根据用户手动提供的多篇文献写综述；
- 将文献笔记整理为课题申报书“研究现状”；
- 将参考文献和摘要整理为论文引言；
- 对已有综述做逻辑重组和研究述评；
- 整理 GB/T 7714-2015 参考文献。

## 不适合场景

- 处理用户未提供的文献材料；
- 改变用户指定文献集合；
- 按某一机构期刊目录筛选文献；
- 无依据补充不存在的论文、DOI 或期刊信息。

## 输入数量与处理方式

| 用户提供材料 | 推荐处理方式 |
|---|---|
| 1 篇文献 | 单篇文献精读、机制拆解、方法分析、可嵌入综述段落 |
| 3-5 篇文献 | 小型主题梳理、文献比较、初步研究脉络 |
| 10 篇以上 | 完整文献综述、主题聚类、研究述评 |
