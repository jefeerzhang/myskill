# 综述综合写作框架

## 核心原则

Synthesis is not summarization. 文献综述不是把论文逐篇排队，而是解释一个研究问题的知识如何形成、分化和推进。

## 段落组织

一个成熟的综述段落通常包含：

1. 主题句：说明这一组文献共同回答什么问题；
2. 分类句：说明已有研究分成哪几条路径；
3. 证据句：用代表性文献说明每条路径；
4. 关系句：指出递进、对比、补充或分歧；
5. 述评句：指出不足或下一步研究空间。


## 单篇文献精读模板

当材料只有一篇文献时，输出重点应从“综述综合”转为“精读拆解”。可采用以下模板：

```markdown
# 单篇文献分析：[题名]

## 一、文献信息
## 二、研究问题
## 三、理论基础与机制链条
## 四、数据、方法与识别思路
## 五、主要结论
## 六、创新与贡献
## 七、局限与可借鉴之处
## 八、可放入综述中的表述
## 九、参考文献格式
```

### 写作要点

- 研究问题要写成“作者试图解释什么关系或现象”，不要只复制题名；
- 机制链条要尽量改写成“前因、过程、结果、边界条件”；
- 方法部分要区分数据来源、样本范围、核心变量、模型设定和识别假设；
- 结论部分优先提炼与用户研究主题相关的发现；
- “可放入综述中的表述”要写成正式综述段落，便于用户后续拼接到多篇综述中；
- 缺失信息要标注，不要补造。

## 常用结构

### 主题型

适用于多数经济管理类综述。

```markdown
## 一、概念界定与理论基础
## 二、影响效应研究
## 三、作用机制研究
## 四、异质性与边界条件
## 五、研究述评
```

### 时间演进型

适用于政策演进、理论流派和技术扩散主题。

```markdown
## 一、早期研究：问题提出与概念形成
## 二、发展阶段：经验检验与机制拓展
## 三、近期研究：因果识别、异质性与政策优化
```

### 方法比较型

适用于计量识别、测度方法和评价体系主题。

```markdown
## 一、指标测度方法
## 二、因果识别策略
## 三、数据来源与适用边界
## 四、方法局限与改进方向
```

## 研究不足写法

避免泛泛而谈。优先写成具体不足：

- 已有研究更多验证平均效应，对机制链条中哪个环节发生阻滞解释不足；
- 对地区、行业、主体禀赋的跨层异质性处理不充分；
- 使用截面或短面板较多，对政策效应的持续性识别不足；
- 指标更多反映规模变化，较少刻画质量、稳定性和分配结果；
- 在多政策叠加背景下，对净效应和空间溢出识别不足。

## 经济管理类写作提示

- 写政策评估时，交代政策冲击、处理组、对照组和识别假设；
- 写企业研究时，区分企业行为、绩效结果和外部治理环境；
- 写农户研究时，区分收入水平、收入结构、收入稳定性和生计能力；
- 写数字经济时，区分基础设施接入、平台使用、数据要素和组织变革；
- 写环境经济时，区分排放总量、排放强度、绿色创新、转型风险和金融风险。
