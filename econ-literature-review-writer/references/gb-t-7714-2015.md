# GB/T 7714-2015 参考文献著录简表

## 期刊论文

```text
[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码. DOI.
```

示例：

```text
[1] 张三, 李四, 王五. 数字经济与农业高质量发展[J]. 农业经济问题, 2024(3): 45-58. DOI:xxxxx.
[2] Smith J, Johnson A, Williams B. Climate transition risk and firm valuation[J]. Journal of Finance, 2023, 78(2): 1001-1035. DOI:xxxxx.
```

## 专著

```text
[序号] 主要责任者. 书名[M]. 版本项. 出版地: 出版者, 出版年: 引文页码.
```

## 会议论文

```text
[序号] 主要责任者. 题名[C]//编者. 会议文集名. 出版地: 出版者, 出版年: 起止页码.
```

## 学位论文

```text
[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年份.
```

## 报告

```text
[序号] 主要责任者. 报告名[R]. 出版地: 发布机构, 年份.
```

## 电子资源

```text
[序号] 主要责任者. 题名[EB/OL]. (更新日期)[引用日期]. URL. DOI.
```

## 作者规则

中文作者：3 人以内全部列出，超过 3 人列前 3 人后加“等”。

英文作者：3 人以内全部列出，超过 3 人列前 3 人后加“et al.”。英文作者通常写作“姓 名首字母”，如 `Smith J`。

## 文中引用

按用户要求选择顺序编码制或作者年份制。若用户明确要求国标注释格式，应优先保持其目标期刊、学校或项目申报书要求。
